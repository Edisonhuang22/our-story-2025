# 七夕纪念相册网站 · 设计文档

- 日期：2026-08-18
- 交付截止：2026-08-19（七夕）
- 状态：待用户确认

## 1. 背景与目标

为女朋友做一个记录恋爱点滴的纪念相册网站，作为七夕礼物。核心诉求：左侧 iOS 风格照片叠放（点击/滑动翻页）、右侧对应文字；去掉一切"仪式感过重"的元素（计数器、寄语、情书、结尾祝福语）。

## 2. 已确认的决策

- 实现方案：纯静态站点（HTML/CSS/JS，无构建步骤），GitHub Pages 部署。
- 视觉风格：A · 甜美粉彩（粉色渐变、圆角卡片、爱心元素）。
- 已删除：实时天数计数器、七夕寄语、结尾"七夕快乐"、情书彩蛋。
- 保留：密码页（默认密码 `20251213`，纯前端校验，防链接外泄）。
- 顶部：标题"小小怪下士" + 一行小字"2025.11 – 2026.05"。

## 3. 页面结构

单页长滚动，无路由：

1. **密码页（覆盖层）**：全屏遮罩，输入密码后淡出进入。密码以 SHA-256 哈希形式存放在前端。
2. **页头**：标题 + 日期范围小字，粉色渐变背景。
3. **时间轴主体**：29 个章节，按时间正序。每个章节 = 左侧照片叠放（点击/左右滑动/箭头翻页，计数器显示"x / n"）+ 右侧文字（日期、标题、正文）。
4. 结尾无任何文案，最后一章即结尾。

响应式：宽度 < 760px 时照片在上、文字在下。

## 4. 视觉规范

- 背景：`#ffe9f2 → #fff7fa` 渐变；卡片白色圆角 `16–20px`，粉色系阴影。
- 强调色：`#d34a7a` / `#c22a63`；正文深灰 `#4a3a42`。
- 字体：系统字体栈（不依赖国外字体库）。
- 装饰：低透明度缓慢飘落的爱心粒子（少、慢，避免喧宾夺主）。
- 照片卡片：白色描边 + 圆角，叠放时下层照片露出约 16px 边缘、轻微旋转。

## 5. 照片管线

输入 `photos/`（29 个日期文件夹，88 个文件：HEIC×46、JPG×32、JPEG×1、PNG×9），输出 `site/img/`：

1. HEIC → JPEG：使用工作区自带 `heif-convert.exe`（已验证可用）。
2. Pillow：EXIF 自动转正 → RGB → 长边缩至 1400px → 渐进式 JPEG，质量 82。
3. 每章照片按文件名自然排序（拍摄顺序），输出为 `img/<日期>/<序号>.jpg`。
4. 生成 `site/data/photos.json`，记录每章照片清单与尺寸。

预计总量 < 20MB，手机流量可接受。

## 6. 数据模型

`site/data/events.json`（手写内容）+ `site/data/photos.json`（管线生成），前端按 `folder` 键合并：

```json
{
  "folder": "2025.11.19",
  "date": "2025年11月19日",
  "title": "第一张照片",
  "text": "第一次在生科馆看见你们，当时童昊指着你俩不知道说了什么，我觉得很好笑就拍了一张照片哈哈哈。"
}
```

## 8. 隐私与部署

- GitHub 仓库设为公开（免费 Pages 前提），链接不公开；密码页挡住陌生人。
- 部署：GitHub Actions（`actions/deploy-pages`）将 `site/` 发布为 Pages 站点。
- 站点长期有效；删除仓库即下线。原始照片（`photos/`）不进入 git，仅压缩产物入库。

- 桌面与 375px 宽视口布局正确；所有图片 HTTP 200。
- 页面总资源 < 25MB。
